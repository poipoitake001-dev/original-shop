# 管理后台升级说明

## 已完成的升级内容

### 1. 新增"支付设置"功能模块 ✅

**位置**：侧边栏"店铺装修"和"用户管理"之间

**功能特性**：
- **API 网关支付**
  - 开关控制
  - API 网关地址配置
  - 商户 ID 和密钥配置
  - 异步通知地址（只读，自动生成）
  
- **手动二维码支付**
  - 开关控制
  - 收款二维码上传（支持点击上传本地图片，自动转 Base64）
  - 支付说明文字配置
  - 图片预览和删除功能

**技术实现**：
- 图片上传自动转 Base64 存储
- 文件大小限制 2MB
- 支持 JPG、PNG 等常见图片格式
- 实时预览功能

### 2. 重构"店铺装修"页面 ✅

**主要改进**：
- ❌ 取消了繁琐的 Tab 分页（基本信息/外观设置/联系方式）
- ✅ 改为现代化的单页垂直滚动布局
- ✅ 所有设置一目了然，操作更流畅

**图片上传升级**：
- ❌ 旧版：手动输入图片 URL（体验差）
- ✅ 新版：点击上传本地图片（自动转 Base64）
- 涉及字段：
  - 网站 Logo
  - Favicon 图标
  - 客服二维码
  - 核心优势徽章图标（3 个）

**新增配置区域**：
- **核心优势徽章**（3 个）
  - 标题
  - 描述
  - 图标上传
  
- **社交账号**
  - 微博链接
  - 抖音链接
  - 小红书链接
  - B站链接

### 3. 样式优化 ✅

- 保持深色主题（Dark Mode）
- 卡片式布局，视觉层次清晰
- 统一的输入框和按钮样式
- 图标配色（蓝色/紫色/黄色/绿色/粉色）增强视觉识别
- 悬停效果和过渡动画
- 响应式布局支持

## 使用说明

### 支付设置页面
1. 进入"支付设置"菜单
2. 根据需要开启 API 网关支付或手动二维码支付
3. 填写相关配置信息
4. 点击"保存设置"

### 店铺装修页面
1. 进入"店铺装修"菜单
2. 向下滚动查看所有配置区域
3. 点击"点击上传图片"按钮上传本地图片
4. 图片会自动预览，可点击删除按钮移除
5. 填写完所有信息后点击"保存设置"

## 技术细节

- 图片上传采用 FileReader API 转 Base64
- 文件验证：类型检查 + 大小限制
- 上传状态管理：防止重复上传
- 错误处理：友好的提示信息
- 响应式设计：支持桌面和平板设备
