# 管理后台升级说明

## 已完成的升级内容

### 1. 新增"支付设置"功能模块 ✅

**位置**：侧边栏"店铺装修"和"用户管理"之间

**功能特性**：
- **API 网关支付**
  - 开关控制
  - API 网关地址配置
  - 商户 ID 和密钥配置
  - 异步通知地址（只读，自动生成）
  
- **手动二维码支付**
  - 开关控制
  - 收款二维码上传（支持点击上传本地图片，自动转 Base64）
  - 支付说明文字配置
  - 图片预览和删除功能

**技术实现**：
- 图片上传自动转 Base64 存储
- 文件大小限制 2MB
- 支持 JPG、PNG 等常见图片格式
- 实时预览功能

### 2. 重构"店铺装修"页面 ✅

**主要改进**：
- ❌ 取消了繁琐的 Tab 分页（基本信息/外观设置/联系方式）
- ✅ 改为现代化的单页垂直滚动布局
- ✅ 所有设置一目了然，操作更流畅

**图片上传升级**：
- ❌ 旧版：手动输入图片 URL（体验差）
- ✅ 新版：点击上传本地图片（自动转 Base64）

  - 网站 Logo
  - Favicon 图标
  - 客服二维码
  - 核心优势徽章图标（3 个）

**新增配置区域**：
- **核心优势徽章**（3 个）
  - 标题
  - 描述
  - 图标上传
  - 直接修改前端页面显示的三个方框内容
  
- **社交账号**
  - 微博链接
  - 抖音链接
  - 小红书链接
  - B站链接

### 3. 样式优化 ✅

- 保持深色主题（Dark Mode）
- 卡片式布局，视觉层次清晰
- 统一的输入框和按钮样式
- 图标配色（蓝色/紫色/黄色/绿色/粉色）增强视觉识别
- 悬停效果和过渡动画
- 响应式布局支持

### 4. 数据库升级 ✅

**新增表结构**：
- `site_settings` - 站点设置表（包含所有配置）
- `trust_badges` - 信任徽章表（备用）
- `info_pages` - 信息页面表（服务条款等）

**后端 API 升级**：
- 支持所有新增字段的保存和读取
- 优化了字段更新逻辑，支持批量更新

## 🚀 部署步骤

### 第一步：执行数据库迁移

**方法一：使用 Node.js 脚本（推荐）**
```bash
node backend/scripts/migrate.js
```

**方法二：使用 MySQL 命令行**
```bash
mysql -u root -p
source database/migrations/add_settings_tables.sql
```

**方法三：手动执行**
1. 打开 `database/migrations/add_settings_tables.sql`
2. 在 MySQL 客户端中执行全部内容

### 第二步：重启后端服务

```bash
cd backend
npm start
```

### 第三步：重启前端服务

```bash
# 管理后台
cd admin
npm run dev

# 用户前端
cd frontend
npm run dev
```

### 第四步：验证功能

1. 登录管理后台
2. 进入"支付设置"页面，测试保存功能
3. 进入"店铺装修"页面，测试图片上传和核心优势配置
4. 访问前端页面，查看核心优势徽章是否正确显示

## 使用说明

### 支付设置页面
1. 进入"支付设置"菜单
2. 根据需要开启 API 网关支付或手动二维码支付
3. 填写相关配置信息
4. 点击"保存设置"

### 店铺装修页面
1. 进入"店铺装修"菜单
2. 向下滚动查看所有配置区域
3. 点击"点击上传图片"按钮上传本地图片
4. 图片会自动预览，可点击删除按钮移除
5. 在"核心优势徽章"区域配置前端显示的三个方框内容
6. 填写完所有信息后点击"保存设置"

### 核心优势徽章配置
- 在"店铺装修"页面的"核心优势徽章"区域配置
- 配置后会直接影响前端页面显示的三个方框
- 默认内容：
  1. 本平台仅在线支付
  2. 诚信交易，真假自辨
  3. 触达校园与新专台

## 技术细节

- 图片上传采用 FileReader API 转 Base64
- 文件验证：类型检查 + 大小限制
- 上传状态管理：防止重复上传
- 错误处理：友好的提示信息
- 响应式设计：支持桌面和平板设备
- 前端核心优势组件从 `site_settings` 表读取配置

## 故障排查

### 问题：保存设置时提示"更新设置失败"

**解决方案**：
1. 检查数据库迁移是否执行成功
2. 查看后端控制台错误日志
3. 确认 `site_settings` 表是否存在
4. 验证数据库连接是否正常

### 问题：前端核心优势不显示

**解决方案**：
1. 在管理后台"店铺装修"页面配置核心优势徽章
2. 检查浏览器控制台是否有 API 错误
3. 确认 `/api/settings/public` 接口返回正常
4. 清除浏览器缓存后刷新

### 问题：图片上传后不显示

**解决方案**：
1. 检查图片格式是否支持（JPG、PNG）
2. 确认图片大小不超过 2MB
3. 查看浏览器控制台是否有错误
4. 尝试使用不同的图片
